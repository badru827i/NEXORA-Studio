# NEXORA Studio Roadmap

## Foundation
- [x] Clean Compose navigation and neutral design
- [x] Video, image and audio picker
- [x] Timeline workspace with trim and speed controls
- [x] Split marker interaction
- [x] USB attach/detach detection
- [x] Android build, lint and unit-test workflow
- [x] Lightweight local SQLite project save and reopen
- [x] Device inventory for SoC vendor/model, CPU, RAM, Vulkan exposure and thermal state
- [x] Cache usage report and temporary-cache cleanup
- [x] GLES 3.1 GPU compute block matching with automatic CPU fallback
- [x] Actual tracking backend reporting in the editor
- [ ] Persistent autosave during editing
- [ ] Frame-accurate editing and Media3 preview/export

## Editing suite
- [ ] Multi-track timeline and clip dragging
- [ ] Crop, rotate, resize and aspect presets
- [ ] Audio mixer, fades and waveform
- [ ] Text, captions and subtitle import/export
- [ ] Transitions, keyframes and effects
- [ ] Color and LUT controls
- [ ] Undo/redo history

## Render farm
- [ ] NEXORA Worker companion app
- [ ] Local discovery and pairing
- [ ] USB transport where Android roles permit it
- [ ] Job queue, hardware negotiation and thermal scheduling
- [ ] Chunk render, checksum, retry and result assembly

## 3D
- [ ] Real-time viewport and camera
- [ ] Primitive modelling and transforms
- [ ] Materials, lighting and mesh import/export
