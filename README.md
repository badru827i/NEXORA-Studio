# NEXORA Studio
A clean, mobile-first creative editor for Android.

## Design
Professional, smooth and easy to use: neutral colors, clear hierarchy, simple tools and no sci-fi styling.

## Foundation
- Kotlin and Jetpack Compose Android application
- Video, image and audio media picker
- Editor workspace with preview, timeline, trim and playback-speed controls
- Media library, projects, USB/OTG device detection and 3D workspace section
- Android GitHub Actions build, lint and unit-test workflow

## Planned modules
Persistent projects and autosave; frame-accurate editing and Media3 export; multi-track editing; audio mixer; text and subtitles; transitions and keyframes; color tools; NEXORA Worker and local render-farm pairing; 3D viewport and mesh import/export.

This is the first application foundation, not yet a finished professional NLE. Advanced editing, video export, 3D rendering and distributed worker execution remain implementation milestones.
